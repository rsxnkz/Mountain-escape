# MOUNTAIN ESCAPE

## О проекте

MOUNTAIN ESCAPE — многостраничный сайт для бронирования уютных домиков в горах.

Сайт позволяет познакомиться с вариантами проживания, узнать их стоимость и оставить заявку на бронирование.

## Структура проекта

- index.html — главная страница
- houses.html — страница с домиками
- booking.html — страница бронирования
- style.css — таблица стилей

## Используемые технологии

- HTML5
- CSS3
- JavaScript
- Git
- GitHub

## Основные возможности

- Навигация между страницами
- Просмотр вариантов домиков
- Форма бронирования
- Автоматический расчёт стоимости проживания
- Адаптация под мобильные устройства
